# Forge Sales Desk

A customer-facing prototype for industrial sales planning, resource costing, and negotiation workflows.

## Demo

Deploy the repository to Vercel with no environment variables. Without `NEXT_PUBLIC_API_URL`, the app opens directly in demo mode with illustrative sample deals and negotiation history. Edits are saved in the current browser only, using local storage.

The optional Render API and PostgreSQL setup is documented in [HANDOVER.md](HANDOVER.md), but is not needed for a customer demo. The demo data is illustrative and should not be presented as real customer negotiation research.
